# Apology Archaeology

> Excavate your old messages and turn every sorry into a fossil.

An AI tool that excavates your old messages and turns every apology into a dated fossil layer. It scores sincerity, detects recurring regret patterns, and prints a small museum plaque for your most dramatic sorry.

## Features
- Import chats, emails, or text exports and extract apology events
- Cluster messages into stratified layers by tone, topic, and time
- Assign a sincerity score and a fossil badge to recurring apologies
- Generate a printable museum plaque with the most over-apologized incident

## Stack
- Python
- FastAPI
- OpenAI API
- SQLite

## Getting started
```
pip install -r requirements.txt && export OPENAI_API_KEY=your_key && uvicorn app.main:app --reload
```
